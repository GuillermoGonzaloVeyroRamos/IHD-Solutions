# IHD Solutions - Landing Page

Este repositorio contiene el código fuente de la página web oficial de **IHD Solutions**. Es un sitio diseñado con un enfoque en la experiencia de usuario (UX) y un diseño moderno y minimalista, ideal para presentar soluciones de servicios o consultoría.

## 🚀 Características
- **Diseño Responsivo:** Optimizado para dispositivos móviles, tablets y computadoras de escritorio.
- **Arquitectura Limpia:** Estructura de archivos organizada para facilitar el mantenimiento.
- **Carga Rápida:** Optimización de recursos y activos (assets) para mejorar el rendimiento del sitio.
- **Diseño Moderno:** Uso de CSS avanzado para una estética profesional y corporativa.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Para la estructura semántica del contenido.
- **CSS3:** Estilizado personalizado, incluyendo Flexbox y CSS Grid para el diseño del layout.
- **Assets:** Gestión de imágenes y recursos visuales optimizados.

## 📂 Estructura del Proyecto
- `index.html`: Archivo principal que contiene la estructura del sitio.
- `/assets`: Carpeta que incluye imágenes, iconos y estilos adicionales utilizados en la página.
